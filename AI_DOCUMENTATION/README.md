# AI documentation

- `conversation-export.json` is the full conversation with Claude Code that built this project, exported from the session transcript. It holds every prompt, every assistant reply, every tool call with its input, and every tool result, in chronological order with timestamps.
  - The `completeness` field says what is not included: hidden model reasoning, binary image data (marked with placeholders), harness system notes, and the user's e-mail address, which is redacted.
- `../docs/AI_WORKFLOW.md` is the short, readable summary of the same work.
